# Como gerar as animacoes e colocar a musica na Unity

1. Abra este projeto na Unity.
2. Aguarde a Unity importar os novos arquivos e compilar os scripts.
3. No menu superior, clique em `Tools > Character Demo > Build All Deliverables`.
4. Abra a cena `Assets/Scenes/CharacterDemoScene.unity`.
5. Aperte Play para ver o personagem alternando entre Idle, Walk, Run, Jump, Punch, Power, Hurt e Dead com a musica tocando.
6. Grave o video demonstrativo pela Game View, garantindo que o audio do sistema esteja ativo.

Arquivos principais:

- `Assets/CharacterDemo/CharacterSpriteSheet.png`
- `Assets/CharacterDemo/Audio/BeepBox-Song.mp3`
- `Assets/Scenes/CharacterDemoScene.unity`
- `Assets/CharacterDemo/JustificativaTecnica.md`
